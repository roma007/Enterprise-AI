## 五、验收标准（A1 + A2）

| # | 标准 |
|---|---|
| 1 | 未登录访问任何 `/api/*` 返回 401；访问页面跳登录 |
| 2 | 四种角色：admin / operator / finance / viewer，越权返回 403 |
| 3 | viewer 只能 GET，不能改任何数据 |
| 4 | 每条解析与确认记录带 `actor`（谁做的） |
| 5 | 管理员能建用户、改角色、停用 |

| 7 | 会话可撤销（强制下线） |
