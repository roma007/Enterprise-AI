## 2. 变更分组

### 2.1 多租户与交付架构

- `organizations` 增加 `slug` / `status` / `settings`；同一邮箱按 `org_slug` 登录。
- PostgreSQL RLS + 请求级组织上下文；受限数据库角色 `ai_delivery_app`；请求内连接复用。
- 平台管理员 `users.is_platform_admin`；租户列表、暂停/恢复、组织设置。
- 套餐、试用、配额、账单、模拟支付、HMAC 回调、自动续费任务。
- Redis 登录限流与会话缓存（未配置自动回退内存）。
- PDF 任务 PostgreSQL 队列 + `FOR UPDATE SKIP LOCKED`；缓存支持 local / S3。
- 多副本 Compose 与 K8s 清单、SLO 告警、逻辑备份与 PITR 演练。

### 2.2 试点一：对账复核

- ai-copilot 抽取结果回写平台（`idempotency_key` 幂等）。
- 复核页：单据信息、明细、差异、决策。
- 差异依据：来源（模型+规则 / 规则 / 模型）、置信度、证据。
- 决策编辑：单条与批量（采纳 / 忽略 / 待确认），覆盖保留备注，忽略项退出批量生成。
- 批量生成风险/待办：流式进度、历史、失败重试、取消、继续剩余、分页与父子树。
- 命名筛选视图：个人 / 全员 / 按角色 / 指定同事，可重命名。
- 复核列表：决策状态筛选、单据号/运单号搜索、决策进度徽标。
- 报告：Markdown / Word / PDF，含差异分布、差异汇总、逐条依据、已生成风险/待办。
- 报告交付物：生成、过期检测、审批/外发拦截、重复生成复用、一键重新生成。
- 差异分布：项目级统计与 CSV、单复核摘要、按类型分组折叠、来源/置信度筛选（写入 URL）。

### 2.3 协作审计

- 统一审计：通知、筛选视图、导出、差异决策。
- 通知：未读数、类型/日期筛选、跨页全选批量删除、回收站、批量已读、点击即读、筛选视图（个人/共享/角色/指定）。
- 审计归档：热表 → `audit_logs_archive`、归档执行历史与导出、归档查询/导出。
- 每日快照：按组织时区生成、热表+归档口径、日/周/月聚合、新增/累计、环比、分面长表导出、保留期清理。
- 周期报告 Word（新增环比、类型分布、高频操作、活跃操作人、趋势）。
- 周报站内通知（管理员/总监/项目经理，6 天去重，点击带日期范围）。
- 看板：7/30/90 天、迷你趋势与悬停、按日下钻、点击滚动到列表。
- 个人/共享筛选视图：保存、套用、重命名、共享提醒与深链。

## 6. 兼容性与风险

1. **RLS 依赖数据库角色**：无法创建/授权 `ai_delivery_app` 时需 DBA 预授权。
2. **PDF 依赖服务端浏览器**：无 Chromium/Edge 时返回 503；Word/Markdown 不受影响。
3. **报告为生成时快照**：决策变化后标记过期，需重新生成；审批/外发会拦截。
4. **快照口径**：累计包含归档；归档被清理后累计可能下降（导出/图表按 0 截断）。
5. **通知为站内消息**：没有邮件/Webhook；周报 6 天去重。
6. **时区**：快照按组织时区；修改时区后可手动重算历史日期。

## 8. 评审建议关注点

1. **租户隔离**：RLS 策略、平台管理员绕过、跨组织共享校验。
2. **决策与批量动作**：事务边界、幂等、整批校验不部分写入。
3. **报告过期**：内容哈希口径、审批/外发拦截、重复生成复用。
4. **快照口径**：热表+归档、时区、同日唯一、归档后累计不下降。
5. **共享权限**：全员/角色/指定对象的可见范围与创建者限制。
6. **测试覆盖缺口**：新页面尚无组件级测试；e2e 只覆盖关键路径。
