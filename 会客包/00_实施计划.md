## 0. 为什么需要这份计划

之前的做法是"做一件、想一件"，已经造成三个具体问题：

| 问题 | 表现 | 代价 |
|---|---|---|
| 优先级靠感觉 | 先做了机会地图，又跳到 demo，01/03/05 一直没做 | 会客材料不齐，无法判断"什么时候能出门" |
| 没有完成定义 | demo "能跑" 就算完成，实际缺 OCR、缺真实样本、缺模型 | 现场被问一句就露怯 |
| 无法拒绝新想法 | 每聊到一个点就想加功能 | 范围持续膨胀，没有一项做透 |

本计划的作用只有两个：**给出唯一的执行序列**，**给出唯一的完成定义**。

## 1. 目标与边界

### 1.1 阶段目标（未来 3 个月）

拿到 **1 个真实客户**，完成 **1 个真实场景的 POC**，并用你的交付平台把整个过程管起来（吃自己的狗粮）。

### 1.2 成功标准（可量化，缺一不可）

| # | 标准 | 判定方式 |
|---|---|---|
| S1 | 目标客户完成首次会客，并**交付 200 份真实托书样本 + 1 名内部 owner** | 样本入库到 `ai-copilot/samples/real/` |
| S2 | 在真实样本上，托书字段级准确率 ≥ **95%** | `app.evalrun` 跑真实集 |
| S3 | 人工修正 ≤ **1 分钟/单** | 遥测 `feedback` 表统计 |
| S4 | 客户签署 POC 意向（哪怕免费试点） | 有书面记录 |
| S5 | 该 POC 在交付平台里走通 S1→S3，G1/G2/G3 门禁有证据 | 平台内可查 |
| S6 | 产出 1 份可复用的行业样板（第二家客户能直接用） | 复用率自评 ≥60% |

### 1.3 明确不做（本阶段一律不碰）

| 不做 | 理由 |
|---|---|
| 智能调度 / 配载优化 | 依赖货源池与司机意愿，12 个月内不具备条件 |
| TMS / 财务软件对接 | 接口风险会把 3 周拖成 3 个月 |
| 登录 / 权限 / 多租户 / 计费 | 演示与 POC 阶段的纯浪费 |
| 工具库 / 插件机制 / 低代码配置 | 只有 2 个应用，抽象一定是错的 |
| 客户门户 | 已在平台侧决策为"不做门户" |
| 通用文档处理（非集卡行业） | 通用 = 谁都不信 |

## 3. 阶段划分与门禁

沿用 `00_总体规划.md` §6 的阶段模型，把售前与落地挂进去，不另造一套。

```
P0 收口        P1 会客包文档      P2 Demo 加固        P3 首次会客        P4 二次会客+提案     P5 POC 执行
(1d)     →     (2.5d)       →    (7d)          →    (外部)       →    (外部)        →    (12 周)
                  │                  │                  │                  │                  │
                G0 计划批准        G1 出门门禁        G2 样本门禁        G3 立项门禁        G4 POC 结项
                                 (可约客户)       (拿到200份样本)     (客户签意向)      (S2达标)
```

| 门禁 | 名称 | 通过条件（缺一不可） |
|---|---|---|
| **G0** | 计划批准 | 本文件被确认；§9 的 5 个决策全部拍板 |
| **G1** | 出门门禁 | ① smoke 全绿 ② 文本+图片都能解析 ③ 01/03/05 三份文档齐 ④ 能当场说出"6 个不做" ⑤ 能给出诚实准确率话术 |
| **G2** | 样本门禁 | 真实托书 ≥200 份已入库；客户指定 1 名内部 owner |
| **G3** | 立项门禁 | 真实样本准确率 ≥90%（未达 95% 也可立项，但需写明差距与补齐计划）；POC 范围与验收标准书面确认 |
| **G4** | POC 结项 | 字段级 ≥95%；修正 ≤1 分钟/单；交付平台 S1→S3 有完整证据 |

> **G1 是硬门禁。** 未通过不许约客户——空手去一次，第二次就很难约。

## 6. 关键路径

```
P2-3 OCR ──→ P2-4 样本集 ──→ P2-5 就绪检查 ──→ G1 ──→ P3-2 首次会客 ──→ P3-3 样本
     ↑                                                                      ↓
P2-1 模型 ──────────────────────────────────────────────────────────→ P4-1 真实评测
                                                                            ↓
                                                                      G3 ──→ P5
```

**关键路径上的单点风险是 P2-3（OCR）。** 它一旦延期，G1 整体顺延。因此：
- 先做 PDF 文本层（简单），再做图片（难）
- 若 W3 周三仍未跑通图片，走降级方案，用"现场手打一段话"过渡
