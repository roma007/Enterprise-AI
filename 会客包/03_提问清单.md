# 会客提问清单（现场表）

> 用途：第一次会客的 20 分钟问答段。
> 原则：**不问"你想不想要 AI"，只问能算出账的事实。**
> 记录方式：现场直接在本表"记录"列写客户原话，会后 2 小时内转誊。

---

## 使用说明

1. 三档判定自己勾：**好**（可直接立项）/ **中**（需补充材料）/ **差**（该场景降级或砍掉）
2. 每题后面标了"影响"，答完就知道哪个机会点能留、哪个必须砍
3. **客户说"不清楚"是重要信息**，不算没答——说明这块连基线都没有
4. 全程不超过 20 分钟，剩下的时间留给 demo 和收尾

---

## A. 业务侧（10 问）

| # | 问题 | 追问 | 现场记录 | 判定 | 影响 |
|---|---|---|---|---|---|
| A1 | 现在多少台车？自有和外协各占多少？ | 外协的车怎么调度、怎么结算？ | | ☐好 ☐中 ☐差 | 决定 ROI 量级（<30 台只建议买 SaaS） |
| A2 | 去年营收、毛利率大概多少？ | 净利大概几个点？ | | ☐好 ☐中 ☐差 | 决定值不值得做（净利 <3% 时投入更谨慎） |
| A3 | 订单从哪来？微信/QQ、邮件、电话、系统各占多少？ | 微信里发的是文字、截图还是 Excel？ | | ☐好 ☐中 ☐差 | **B1 的生死题**；微信占比高 → 价值极大 |
| A4 | 有没有 TMS？用了几年？谁维护？能开放接口吗？ | 是本地部署还是 SaaS？ | | ☐好 ☐中 ☐差 | 决定 B1 是"增强"还是"从零接入"，工期差一倍 |
| A5 | 调度几个人？每人管多少台车？一天处理多少单？ | 单证几个人？一天多少票？ | | ☐好 ☐中 ☐差 | **B1 收益的分母**（工时基线） |
| A6 | 空驶率大概多少？有测算过吗？ | 怎么算的？有数据还是拍脑袋？ | | ☐好 ☐中 ☐差 | B7 的上限；没测算 → B7 直接砍 |
| A7 | 压车费、等候费、改单费，一年大概多少？漏收多吗？ | 现在怎么记这些费用？ | | ☐好 ☐中 ☐差 | B4 的收益基线；说不清 → 先建费用台账 |
| A8 | 车辆装 GPS 了吗？轨迹能留存多久、能导出吗？ | 有没有对接港区/码头预约系统？ | | ☐好 ☐中 ☐差 | B3 / B7 的前置；没有 → 两项都降级 |
| A9 | 客户投诉最多的是什么？ | 最近一次被罚款/索赔是什么事？ | | ☐好 ☐中 ☐差 | **最高价值场景往往藏在这里** |
| A10 | 如果只能解决一个问题，你最想解决哪个？ | 为什么是这个？不解决会怎样？ | | ☐好 ☐中 ☐差 | **决定项目能不能活下去**（解决不了老板的痛，预算批不下来） |

## B. 财务侧（5 问）

| # | 问题 | 追问 | 现场记录 | 判定 | 影响 |
|---|---|---|---|---|---|
| B1 | 用什么财务软件？（金蝶 / 用友 / 自研 / 代账） | 能不能导出明细？能不能对接？ | | ☐好 ☐中 ☐差 | 决定能不能取数、能不能回写 |
| B2 | 发票是什么形态？纸质、电子普票、全电发票各占多少？ | 全电发票能拿到 XML 吗？ | | ☐好 ☐中 ☐差 | 全电占比高 → 发票识别难度骤降 |
| B3 | 对账单谁做？每月多少份？做一次要多久？ | 是一个人对一家客户，还是混着做？ | | ☐好 ☐中 ☐差 | **对账场景的生死题**；说不清 → 场景直接砍 |
| B4 | 应收账龄现在怎么管？逾期率大概多少？ | 催收谁负责？有账龄表吗？ | | ☐好 ☐中 ☐差 | F3 的收益基线 |
| B5 | 外协车队怎么结算？按趟、按吨还是按月？有合同价表吗？ | 结算要几个人、几天？ | | ☐好 ☐中 ☐差 | F4 的可行性；口头结算 → 先建规则 |

> **B3 是全场最值钱的一问。** 如果答案是"2 个人做 5 天/月"，ROI 当场能算，客户自己会算；
> 如果答案是"财务说不清"，说明这块连基线都没有——而这正是你比他专业的地方。

## C. 组织与样本（4 问，决定能不能做，而不是做什么）

| # | 问题 | 追问 | 现场记录 | 判定 |
|---|---|---|---|---|
| C1 | 这件事最终谁拍板？ | 预算走什么流程？大概多久？ | | ☐好 ☐中 ☐差 |
| C2 | 如果做，谁做内部负责人？每周能投入多少时间？ | 他能调动调度和单证吗？ | | ☐好 ☐中 ☐差 |
| C3 | 能不能给 200 份真实托书？什么格式？谁提供？ | 需要脱敏吗？走什么审批？ | | ☐好 ☐中 ☐差 |
| C4 | 你们 IT / 安全对数据出公司和出境，有什么硬要求？ | 能不能用境内模型？能不能私有化？ | | ☐好 ☐中 ☐差 |

> **C2 答"没有"= 否决信号。** 行业里烂尾的项目，九成是没有内部 owner。
> 这一条要当场说出口："如果没有这个人，我建议先别做。"

## D. 现场评分卡（离开客户前 3 分钟填完）

| 维度 | 看哪几题 | 得分（1–5） | 判断 |
|---|---|---|---|
| **价值** | A2, A5, A7, A9, A10 | | ≤2 分：不值得做定制 |
| **可行性** | A3, A4, A8, B1, B2 | | ≤2 分：先补数据/系统，别做 AI |
| **组织** | C1, C2, C4 | | ≤2 分：**不建议立项** |
| **基线** | A5, A7, B3, B4 | | ≤2 分：先建台账，3 个月后再来 |

> **A10 答得好，价值维度可以直接给 4 分以上。**
> 因为"单证招不到人""司机不听系统"这类原话，比任何 ROI 数字都更能决定项目能不能活。
> 反过来，如果 A10 答"没什么特别想解决的"，就算 A2/A5 数字再漂亮，也不要推进。

**结论规则**

- 任一维度 ≤2 分 → 本期不做，转为"轻咨询 + 数据准备"
- 四项均 ≥3 分 → 进入第二轮，做真实样本评测
- 组织 ≤2 分或 C3「拿不到样本」→ **无论其他多好，都不推进**

## E. 会后 24 小时内必须做的 4 件事

| # | 动作 | 产出 |
|---|---|---|
| 1 | 把记录列转成文字，回填到本表 | 一份可交付的会议纪要 |
| 2 | 把 A/B/C 三节的答案填进 `02_机会地图.md` §0.1 的 C1–C3 参数位 | 机会地图从模板变成客户版 |
| 3 | 按 D 节评分，写一句结论（推进 / 暂缓 / 不推荐） | 一句话，不写长文 |
| 4 | 24 小时内发一封确认邮件：**只写我们听到了什么、下一步要什么**，不写方案 | 留痕 + 建立专业感 |

## 附：绝对不能问的 5 个问题

| 别问 | 为什么 |
|---|---|
| "你们想用 AI 做什么？" | 客户不知道，只会说"都想试试"，把范围炸开 |
| "预算多少？" | 太早，且会让对方防御。用 C1 的"预算走什么流程"替代 |
| "你们数据质量怎么样？" | 客户会答"挺好的"，没有信息量。问 A3/A4/A8 的具体事实 |
| "竞品你们看过吗？" | 把话题引向比价，失去专业位置 |
| "我们能给你做个小 demo 吗？" | 免费 demo 换不来承诺。用"给我 200 份样本，我 3 周后带报告回来"替代 |
